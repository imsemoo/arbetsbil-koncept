# Arbetsbil Stockholm – koncept

Klickbar designprototyp för arbetsbil.se, framtagen som förslag av Eslam Nasser (imsemoo).
Desktop: `index.html`, `bil.html`. Mobil: `mobil.html`, `bil-mobil.html`.

Statisk prototyp med fasta bredder (1440 / 390) som skalas för att passa skärmen. Inte produktionskod.
Bilder, logotyp och priser tillhör Arbetsbil Stockholm AB och är hämtade från deras publika webbplats för detta förslag.
